# Prophetic School Signup

A modern registration form for the Ruach Apostolic & Prophetic Training School.

## Features

- Student registration with comprehensive information collection
- Name, Surname, Age, Address
- Contact Details
- Church Name
- Area of Gifting
- Reason for attending the course
- Direct WhatsApp integration for submissions

## Development

Requirements: Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
